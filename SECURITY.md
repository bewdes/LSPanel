# Security Policy

Security is important for LS Panel because the application interacts with local development environments, containers, networking, certificates, and project data.

## Supported Versions

LS Panel is currently in beta development.

Security fixes are generally provided for the latest available release.

| Version             | Supported |
| ------------------- | --------- |
| Latest beta release | ✅        |
| Older releases      | ❌        |

Users are encouraged to update to the latest version before reporting a security issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues or Discussions.

Instead, use GitHub's private vulnerability reporting feature for this repository.

When reporting a vulnerability, please include as much relevant information as possible:

- affected LS Panel version;
- operating system and version;
- Docker or Podman version, if relevant;
- a clear description of the vulnerability;
- steps required to reproduce it;
- potential security impact;
- proof of concept, logs, or screenshots where appropriate.

Please remove passwords, access tokens, private URLs, personal information, and other unrelated sensitive data before submitting a report.

## Disclosure

Please allow reasonable time for the vulnerability to be investigated and, where necessary, fixed before publishing details publicly.

Confirmed vulnerabilities may be handled through GitHub Security Advisories and disclosed after an appropriate fix is available.
